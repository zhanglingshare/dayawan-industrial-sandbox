# 大亚湾产业沙盒 · 七幕剧

把惠州大亚湾石化产业系统拆成节点、关系、变量与时间，装进一台可交互的"产业风洞"里跑一遍。
单文件离线 HTML，无需联网、无需安装、无需权限，双击即开。

## 在线预览

**https://zhanglingshare.github.io/dayawan-industrial-sandbox/**

## 这是什么

不是一份分析报告，而是一台**可复现的压力测试机器**。

你可以拖动滑块，把某个核心项目的投产时间往后拖两年；可以关掉一条产业路径；可以改变一个权重；甚至删掉一条你认为很重要的关系——然后观察整个系统会发生什么。

- 34 个产业主体节点
- 77 条产业关联（供应 / 管道 / 物流 / 上下游 / 配套）
- 4 条发展路径：龙头扩能 · 南北一体化 · 港口贸易 · 城市承载
- 1 个核心实验：仅推迟投产两年，达标概率从 62.4% → 45.5% → 7.3%

## 数据血统（四级标注，全程透明）

| 等级 | 含义 |
|---|---|
| **A** | 公开实测：统计公报 / 管委会工作报告 / 规划文件 / 上市公司公告 |
| **B** | 权威媒体报道交叉验证 |
| **C** | 结构校准：依据公开增速回推的历史序列 |
| **D** | 模型假设：边权重、路径贡献区间、直接影响强度矩阵 |

界面上每个数字都标注了它属于哪一级——你看到一个数字，就知道它是事实、推估，还是假设。

## 模型边界（请先读）

- **这不是预言**，不是对 2030 年的精确预测，也不是投资建议。
- **相关 ≠ 因果**：九年历史序列只测同步性，不做因果路径估计——单一地区、有限样本的汇总数据不足以支撑，估计结果不可识别。
- **你可以推翻我**：所有参数、权重、规则都是显式写在代码里的。改一条边、改一个权重、把投产时间往后拖，再跑一遍。结果跟我不一样，很好——告诉我你改了什么。
- 真正可验证的模型，不该靠作者的权威成立。

## 本地运行

本仓库只有一个 `index.html`，所有 CSS / JS / 数据全部内联。

```bash
# 方式一：直接双击 index.html
# 方式二：本地起服务
npx serve .
# 或
python3 -m http.server 8000
```

浏览器打开即可，无需任何构建步骤。

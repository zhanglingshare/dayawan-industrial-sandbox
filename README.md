# 大亚湾产业沙盒 · 七幕

把惠州大亚湾的石化产业底盘铺进一个可以交互的页面，七幕走完：从建构、现状、结构、角色、影响因素、路径到行动图。

单文件离线 HTML，双击即开，不需要联网、不需要安装。

## 打开方式

直接双击 `index.html`；或在目录下执行 `python3 -m http.server 8000` 后访问 `localhost:8000`。所有样式、脚本与数据都在文件内，没有构建步骤。

## 七幕看什么

| 幕 | 内容 |
|---|---|
| 一 · 建构 | 大亚湾 80 平方公里的产业底盘拆成节点与连线，看它长出来的样子 |
| 二 · 现状与目标 | 2025 年产值 2579 亿元，2030 年公开目标 4000 亿元，中间 1421 亿元的来处 |
| 三 · 结构地图 | 34 个主体、77 条关联，理论最大 561 对连接，看疏密与空档 |
| 四 · 角色与机会 | 谁是不可绕开的节点，谁的位置最讨巧 |
| 五 · 关键影响因素 | 走势、结构、连接、本地循环，四个角度看同一件事 |
| 六 · 路径 | 龙头扩能、南北一体化、港口贸易、城市承载四条路径彼此咬合；可开关、可拖时间 |
| 七 · 行动路径图 | 三阶段路线 |

## 能动手的地方

拖动滑块，把某个核心项目的投产时间往后挪两年；关掉一条路径；调一处强弱；删掉一条关系——然后看整张图跟着怎么变。

## 数据来源

公开实测数据来自统计公报、管委会工作报告、规划文件、上市公司公告；媒体报道作交叉核对。界面上每个数字都标了它的来处，看到一个数字就知道该信到什么程度。

## 边界

这不是对 2030 年的精确预测，也不是投资建议。所有条件都写在代码里，改一条再跑一遍即可——结果不一样是正常的，那说明你改了哪里。
